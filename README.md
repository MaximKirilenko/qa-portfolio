- Ручное тестирование: чек-листы, тест-кейсы, баг-репорты

- Понимание процессов тестирования и жизненного цикла бага

## В процессе изучения

## Что внутри

- `sandbox/` — тренировочная форма регистрации: требования, чек-лист по техникам тест-дизайна, 7 баг-репортов (SBX)
- `api/` — тестирование API: требования, чек-лист из 15 проверок, 1 баг-репорт (API)
- `saucedemo/` — учебный магазин: 6 баг-репортов по разным аккаунтам (SW)
- `Issues` — примеры задач в трекере; полный набор баг-репортов — в файлах выше.
