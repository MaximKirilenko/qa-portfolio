# Баг-репорты: API

API-01. Неверный код ошибки

**Окружение:** Windows 11, Chrome 131, локальная песочница (action=list) 
**Предусловие:** браузер открыт
**Шаги:**
1. Открыть http://localhost:8000/Тестирование/Песочница/api.php????action=item&id=abc
2. На вкладке Сеть нажать на назавание ссылки
3. В открывшемся окне, на вкладке Заголовке обнаружить статус ошибки "Код статуса
404 Not Found"

**Ожидаемый результат:** код **400**
**Фактический результат:** код **404**, в теле поле {"error":"Товар не найден"}

**Severity:** средний
**Priority:** обычный
