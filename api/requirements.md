# Требования к API товаров

Базовый адрес: `api.php`

## 1. Список товаров — `?action=list`

- Код ответа: **200**.
- Тело: JSON-объект с полем `status` = `"ok"` и полем `items` — массив товаров.
- Товаров ровно **3**.
- У каждого товара есть поля: `id` (число), `name` (строка), `price` (число больше 0), `qty` (число 0 или больше).

## 2. Один товар — `?action=item&id=N`

- Если товар существует: код **200**, в теле объект товара с теми же полями.
- Если товара нет: код **404**, в теле поле `error` с текстом ошибки.
- Если `id` не число (например `abc`): код **400**, в теле поле `error`.

## 3. Без авторизации — `?action=secret`

- Код **401**, в теле поле `error`.

## 4. Ошибка сервера — `?action=fail`

- Код **500**, в теле поле `error`.

## 5. Неизвестное действие

- Без параметра `action` или с неизвестным значением: код **400**, в теле поле `error`.

## Общие требования

- `Content-Type` ответа: `application/json`.
- Все сообщения об ошибках — на русском, понятные пользователю.
- В ответах нет паролей, токенов и других секретов.
