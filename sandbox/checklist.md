# Чек-лист: форма регистрации

Проверки составлены по `Требования.md`. Отметка в конце: «+» — работает как должно, «баг» — расхождение.

## Имя

1. не вводить (укажите имя) +
2. ввести имя из 1 символа (регистрация успешна — баг)
3. ввести имя более 50 символов (успех — баг)
4. ввести имя из пробелов (укажите имя) +
5. ввести спецсимволы, знаки (успех — баг)
6. ввести имя в диапазоне 2–50 букв, с пробелами и дефисами +

## Почта

1. не вводить +
2. ввести без @ +
3. ввести без точки (успех — баг)
4. начать пробелом (успех — баг)
5. закончить пробелом (успех — баг)
6. ввести кириллицей (успех — баг)
7. ввести по требованию правильно +

## Телефон

1. не вводить (укажите телефон) +
2. ввести 9 цифр (успех — баг)
3. ввести 10 цифр +
4. ввести 11 цифр +
5. ввести 12 цифр (успех — баг)
6. ввести буквы (успех — баг)
7. ввести корректно, используя +, пробелы, дефисы, скобки +

## Пароль

1. не вводить (укажите пароль) +
2. ввести 7 символов (успех — баг)
3. ввести 6 символов (успех — баг)
4. ввести 5 символов (успех — баг)
5. ввести 4 символа (успех — баг)
6. ввести 3 символа (успех — баг)
7. ввести 2 символа (пароль слишком короткий) +
8. ввести надёжный пароль от 8 символов +
