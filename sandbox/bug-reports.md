# Баг-репорты: форма регистрации

Песочница: `Песочница\index.php`. Эталон: `Песочница\Требования.md`.

---

## BUG-01. Имя из одного символа

**Окружение:** Windows 11, Chrome 131, локальная песочница (index.php)
**Предусловие:** открыта страница регистрации
**Шаги:**
1. В поле «Имя» ввести: `А`
2. Заполнить остальные поля корректно
3. Нажать «Зарегистрироваться»

**Ожидаемый результат:** ошибка «Имя должно быть от 2 до 50 символов», регистрация не выполняется
**Фактический результат:** регистрация проходит, показывается «Регистрация успешна»

**Severity:** средний
**Priority:** обычный
